# Customer Churn Prediction

## Project Overview

This project predicts customer churn using Machine Learning techniques. The goal is to identify customers who are likely to leave a service based on customer demographics, subscription details, and usage patterns.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Model Evaluation

## Dataset

Telco Customer Churn Dataset

## Results

Built a churn prediction model and analyzed the most important factors influencing customer churn.
